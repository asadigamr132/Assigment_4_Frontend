## Description

This project demonstrates HTML forms, HTML5 form validation, and Bootstrap form styling using HTML, CSS, and JavaScript.

## Tasks

- **Task 0 — Basic HTML Form:** A simple contact form with name, email, and message fields.
- **Task 1 — HTML5 Validation:** Form validation using HTML attributes such as `required`, `minlength`, and `maxlength`.
- **Task 2 — Bootstrap Forms:** Responsive forms styled with Bootstrap classes and a grid layout.
- **Task 3 — Bootstrap Validation:** Visual validation feedback for valid and invalid form fields.
- **Task 4 — Registration Form:** A registration form with personal information, password confirmation, gender selection, hobbies, country selection, and validation.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Navigate between the tasks using the navigation bar.
5. Test the forms by entering valid and invalid data.

An internet connection is required to load Bootstrap from the CDN.

## Features

- Responsive layouts using Bootstrap Grid.
- HTML5 validation for required fields and email formats.
- Bootstrap form styling and validation feedback.
- Password confirmation validation.
- Gender selection using radio buttons.
- Hobbies selection using checkboxes.
- Country selection using a dropdown menu.
- Register and Reset buttons.
